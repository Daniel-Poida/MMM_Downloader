# MMM Downloader

Локальное приложение для скачивания **разрешённых вам** видео с YouTube в MP4/H.264. Оно принимает одну ссылку, список ссылок или обычный запрос, например:

> Скачать весь метал с YT

По запросу приложение сначала ищет кандидатов, точно фильтрует длительность, ранжирует выдачу и показывает список. Обычные ссылки тоже сначала можно проверить: приложение получит метаданные и покажет их в той же таблице. В первом столбце отображаются thumbnail, название, кликабельная ссылка и чекбокс выбора.

Основной поток — **«Найти и выбрать» → отметить нужные видео → «Скачать выбранные»**. Для одного шага остаётся вторичная кнопка **«Скачать без просмотра»**. Поиск и предпросмотр не требуют заранее выбирать папку и не зависят от FFmpeg; папка проверяется только перед скачиванием.

## Быстрый запуск на Windows 10/11 x64

1. Распакуйте всю папку приложения в обычную пользовательскую папку, например `Документы\MMM Downloader`.
2. Дважды щёлкните `START_MMM_DOWNLOADER.bat`.
3. При первом запуске дождитесь установки локальных компонентов.
4. Вставьте ссылку или запрос и нажмите **«Найти и выбрать»**. Отметьте нужные строки, выберите папку и нажмите **«Скачать выбранные»**.

Первый запуск скачивает `uv`, Python 3.12, Deno, `yt-dlp` и FFmpeg. Они устанавливаются только внутрь папки приложения (`.runtime` и `.venv`); системный Python не нужен. Архивы запускаемых компонентов закреплены по версиям и проверяются по SHA-256 до распаковки. Для установки и скачивания видео требуется интернет.

## Проверка интерфейса на Mac

Распакуйте архив для Mac и дважды щёлкните `START_MMM_DOWNLOADER_MAC.command`. Скрипт сам скачает проверенные версии `uv` и Deno для Apple Silicon или Intel, создаст изолированную среду в `.runtime-macos` и откроет тот же Qt-интерфейс. Вручную устанавливать Homebrew, Python или Deno не требуется.

Первый запуск может занять несколько минут и использовать около 550 МБ на диске. Этот режим проверяет интерфейс и движок приложения на macOS; Windows-упаковка и Authenticode-подпись проверяются отдельно на Windows.

Полноценная автономная версия для Apple Silicon поставляется как `MMM Downloader.app` в ZIP или DMG. Она уже содержит Python, Qt, FFmpeg, Deno и движок скачивания; устанавливать Homebrew или запускать Terminal не требуется.

Режим по умолчанию — **«Лучший нативный H.264 (быстро)»**: приложение выбирает максимальное разрешение среди доступных H.264-потоков и не тратит время на повторное кодирование. Для абсолютного максимума, включая доступные только в VP9/AV1 разрешения, переключитесь на режим перекодирования.

## Два режима качества

### Лучший нативный H.264 (быстро)

Выбирает максимальное разрешение **среди H.264-потоков**, берёт AAC-аудио и объединяет их в MP4 без перекодирования. Это быстрый и максимально совместимый режим, но на YouTube H.264 нередко заканчивается на 1080p, даже если VP9/AV1 доступны в 1440p или 4K.

Если строгой пары H.264 + AAC у ролика нет, приложение сообщает об ошибке, а не сохраняет другой кодек под видом H.264.

### Абсолютный максимум → H.264 (медленно)

Скачивает лучший доступный поток любого кодека и затем перекодирует его в H.264 (`libx264`, CRF 19) + AAC 192 кбит/с, не уменьшая разрешение. HDR-источники автоматически приводятся к SDR/BT.709, чтобы итог нормально отображался в обычных Windows-плеерах. Так можно получить 1440p/4K H.264, но обработка:

- нагружает процессор;
- требует дополнительного места на диске;
- может идти примерно как длительность ролика или дольше;
- даёт небольшую потерю качества из-за повторного кодирования.

Готовый файл появляется только после успешного окончания конвертации. При ошибке или отмене исходник остаётся в скрытой папке `.mmm-downloader-temp` внутри выбранной папки; повтор того же URL использует ту же временную папку и может продолжить незавершённую загрузку.

## Подборки по обычному запросу

Встроенный локальный парсер понимает русские и английские команды, в том числе:

- количество от 1 до 100;
- «от 10 минут», «не короче часа», «до 30 минут», диапазоны;
- «новые», «популярные», «по релевантности»;
- тему и несколько YouTube-ссылок;
- путь из текста, хотя папка, выбранная в интерфейсе, всегда имеет приоритет.

«Лучшие» означает воспроизводимую сбалансированную оценку по позиции в поиске YouTube, просмотрам и свежести метаданных. Это не объективная оценка качества содержания. Если строгим условиям соответствуют только 14 из 20 роликов, приложение покажет 14 и не ослабит фильтр молча.

## Очередь, восстановление и ошибки

Текущая подборка и состояние скачивания атомарно сохраняются на диск. Если приложение или компьютер были закрыты во время работы, при следующем запуске MMM Downloader предложит вернуть незавершённые позиции в таблицу; загрузка не начнётся без подтверждения пользователя. Готовые файлы, ошибки и стадия перекодирования отмечаются отдельно.

Если часть пачки не скачалась, итог показывается как **«Частично»**, а в таблице появляется кнопка **«Повторить ошибки»**. Повторно запускаются только проблемные позиции. Файл очереди не содержит API-ключей или cookies; там хранятся URL, публичные метаданные видео, выбранная папка и режим качества.

### Необязательный нейро-разбор

Для сложных формулировок включите **«Нейро-разбор»**, добавьте один или несколько API-ключей и выберите нужный из списка. Ключи можно переименовывать при добавлении, переключать и удалять. В этом режиме провайдер получает только текст запроса и возвращает структурированный план; модель не получает доступ к файловой системе или запуску команд.

Поддерживаются два провайдера, и выбирать вручную ничего не нужно — он определяется по самому ключу:

| Ключ | Провайдер | Куда идёт запрос | Модели |
|---|---|---|---|
| `sk-…` | OpenAI | `api.openai.com/v1/responses` | `gpt-5.6-luna`, `gpt-5.6-terra`, `gpt-5.6-sol` |
| `sk-or-v1-…` | OpenRouter | `openrouter.ai/api/v1/chat/completions` | `openai/gpt-5.6-luna`, `google/gemini-2.5-flash-lite`, `openai/gpt-oss-20b` |

Новый ключ проверяется до сохранения запросом, который не тратит токены: у OpenAI это список моделей, у OpenRouter — сведения о самом ключе. Отклонённый ключ (например, отозванный или скопированный не полностью) не попадёт в список, а причина будет названа прямо в окне. Если проверке помешала сеть или лимит запросов, ключ можно сохранить кнопкой **«Сохранить без проверки»**.

Список моделей под ключом всегда принадлежит провайдеру выбранного ключа и переключается вместе с ним; по умолчанию берётся недорогая модель, которой достаточно для разбора запроса. Свой идентификатор можно вписать вручную — он сохраняется, пока подходит провайдеру (у OpenRouter это всегда «автор/модель»). Несуществующая модель будет отклонена сервером, и об этом скажет подпись под запросом.

Запрос плана ограничен 2048 токенами ответа, а размышления модели отключены: план по схеме — это пара сотен токенов, и без потолка OpenRouter резервирует кредиты под максимум модели (у `openai/gpt-5.6-luna` это 128 000 токенов) и отказывает аккаунту с небольшим балансом. Если на счету пусто, впишите в поле модели бесплатный вариант с поддержкой строгих схем, например `nvidia/nemotron-3-super-120b-a12b:free` — у таких моделей свои суточные лимиты, но списаний нет.

Под полем запроса всегда видно, применялся ли ключ: «Запрос разобран через OpenAI, модель …», либо причина отказа и пометка, что сработал локальный разбор. Готовые ссылки нейро-разбор не использует — они разбираются локально. Если разбор не удался, это же повторяется в итоговой строке состояния, чтобы результат не выглядел как обычная удачная подборка.

Секреты сохраняются только в нативном защищённом хранилище операционной системы: Keychain в macOS или Credential Manager в Windows. В `settings.json` остаются лишь названия, маскированные подсказки, провайдер и выбранный профиль; сами ключи не попадают туда или в журнал. Без ключа всё остальное работает через локальный парсер. Запросы к API оплачиваются отдельно по тарифу вашего аккаунта у выбранного провайдера.

## Cookies и ограничения YouTube

По умолчанию используйте **«Без cookies»**. Если YouTube требует вход для ролика, можно выбрать Chrome, Edge или Firefox. Перед этим браузер иногда приходится полностью закрыть, чтобы его cookie-база не была заблокирована.

Приложение не обходит DRM, оплату, приватность или региональные ограничения. OAuth YouTube не используется. Применение cookies аккаунта при массовом скачивании может вызвать защитные ограничения YouTube, поэтому не повышайте объём без необходимости.

Если вы запускаете приложение через `START_MMM_DOWNLOADER.bat` и YouTube изменил выдачу форматов, запустите `UPDATE_ENGINE.bat` — он обновит `yt-dlp` и компоненты поддержки YouTube. В собранном автономном `.exe` зависимости зафиксированы: для обновления нужно заново запустить `BUILD_MMM_DOWNLOADER.bat` из свежей исходной папки или получить новую сборку.

## CLI для автоматизации

Из PowerShell в папке проекта:

```powershell
.\.runtime\uv\uv.exe run --no-sync mmm-downloader `
  "https://youtu.be/VIDEO_ID" `
  --to "D:\Video"
```

Предпросмотр подборки без скачивания:

```powershell
.\.runtime\uv\uv.exe run --no-sync mmm-downloader `
  "Скачать весь метал с YT" `
  --to "D:\Video\Metal" `
  --preview --json
```

Абсолютный максимум с перекодированием:

```powershell
.\.runtime\uv\uv.exe run --no-sync mmm-downloader `
  "https://youtu.be/VIDEO_ID" `
  --to "D:\Video" `
  --quality max
```

Для AI-разбора задайте `OPENAI_API_KEY` в окружении и добавьте `--ai`. Не передавайте секрет отдельным аргументом командной строки.

## Сборка Windows `.exe`

На компьютере с Windows запустите `BUILD_MMM_DOWNLOADER.bat`. Скрипт установит build-зависимости и соберёт автономную папку приложения через PyInstaller:

```text
dist\MMM Downloader\MMM Downloader.exe
dist\MMM-Downloader-Windows.zip
```

В сборку включаются FFmpeg, Deno, `yt-dlp` и компоненты YouTube. PyInstaller не поддерживает надёжную кросс-сборку Windows `.exe` с macOS/Linux, поэтому этот шаг выполняется непосредственно на Windows.

Фирменная иконка с буквой **D** автоматически назначается окну приложения и файлу `MMM Downloader.exe`.

## Сборка macOS `.app`

На Mac с Apple Silicon запустите:

```bash
./scripts/build_macos.sh
```

Сценарий прогонит тесты и соберёт `MMM Downloader.app`, ZIP и DMG в `dist/macos`. В приложение включены FFmpeg и Deno; перед упаковкой выполняется автономная проверка обоих компонентов. Сборка получает локальную ad-hoc подпись. Для распространения без предупреждения Gatekeeper по-прежнему нужны Apple Developer ID и нотариализация Apple.

## Диагностика

- **«Строгая пара H.264 + AAC недоступна»** — переключитесь на режим «Абсолютный максимум → H.264».
- **403 / Sign in to confirm you're not a bot** — обновите движок, уменьшите частоту запросов; при наличии права доступа попробуйте cookies браузера.
- **Найдено меньше нужного** — упростите тему, увеличьте допустимый диапазон длительности или включите нейро-разбор.
- **FFmpeg не найден** — повторно запустите `START_MMM_DOWNLOADER.bat`; при ручной установке можно задать полный путь в `MMM_FFMPEG`.
- **Нет места** — режим перекодирования временно хранит и исходник, и итоговый MP4; освободите минимум двойной ожидаемый объём.
